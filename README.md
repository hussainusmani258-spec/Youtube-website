# 📹 YouTube Home Page Clone

A responsive and pixel-perfect front-end clone of the YouTube Home Page interface built using pure **HTML5** and **CSS3**.

![YouTube Clone Screenshot](./screenshot.png) <!-- Aap apne screenshot ka image path yahan de sakte hain -->

## 🚀 Features

- **Header Section:** Search bar with icons, notification bell, user profile avatar, and voice search setup.
- **Sidebar Navigation:** Expandable sidebar layout with Home, Shorts, Subscriptions, and Explore sections.
- **Categories Filter Bar:** Horizontal scrollable/flex category chips (`All`, `Gaming`, `Music`, `Coding`, etc.).
- **Responsive Video Grid:** Dynamic grid layout using Flexbox for displaying video cards smoothly.
- **Custom Video Cards:**
  - Thumbnail container with duration timestamp overlay.
  - Channel avatar with `flex-shrink` handling to prevent deformation.
  - Video title, channel name, views, and upload duration metadata.

## 🛠️ Tech Stack

- **HTML5:** Semantic structural layout (`<header>`, `<aside>`, `<main>`).
- **CSS3:** Custom styles utilizing Flexbox, CSS Grid, Absolute/Relative Positioning, and FontAwesome icons.
- **FontAwesome (v6.4.0):** Clean UI icons for layout matching.
